Batch Order Select provides a shared, standardized order selection checkbox column and unified action bar for the Zen Cart admin orders listing (Customers > Orders). Instead of every batch-processing module injecting its own checkboxes, duplicate scripts, or stacked button rows, this plugin establishes a single checkbox column and a shared action bar that other plugins (such as Batch Order Print, bulk status updaters, or shipping exporters) can seamlessly hook into.

IMPORTANT: This plugin provides no standalone functionality.
Batch Order Select is a foundational "skeleton" plugin with a sole purpose to establish a shared, standardized checkbox column and a unified action bar which will then be used by other plugins (such as Batch Order Print) to seamlessly hook their buttons into its interface.

Installation & Core Notifier Patching ↑ top

Batch Order Select is built as an Encapsulated Plugin for Zen Cart 2.1.0 and higher. It creates no database tables or configuration keys.

Important Note on Zen Cart Versions:
The leading-column notifiers (NOTIFY_ADMIN_ORDERS_LIST_LEADING_COLUMN_HEADING and NOTIFY_ADMIN_ORDERS_LIST_LEADING_COLUMN_DATA) were officially added to Zen Cart core in v2.3.0.
  • Zen Cart 2.3.0 and newer: 100% zero core file modifications. The installer detects the native notifiers and leaves admin/orders.php completely untouched.
  • Zen Cart 2.1.0 – 2.2.2: Because earlier versions do not include the leading-column notifiers in core, the scripted installer includes a safe, two-step confirmation process that automatically backs up admin/orders.php to admin/orders.php_bos_backup and injects the two missing notifiers.
  1. Backup your store files and database.
  2. Copy the BatchOrderSelect folder into your store's zc_plugins directory so the structure matches:
    zc_plugins/BatchOrderSelect/v1.0.0/manifest.php
  3. In your Zen Cart Admin, navigate to Modules > Plugin Manager.
  4. Locate Batch Order Select and click Install:
    • On Zen Cart 2.3.0+: The plugin installs immediately.
    • On Zen Cart 2.1.0 – 2.2.2: If admin/orders.php does not yet contain the leading-column notifiers, the first click on Install pauses without changing any files and displays a notice explaining the patch. Click Install a second time (within 15 minutes) to confirm and apply the patch, or click Cancel to abort and leave admin/orders.php unchanged. When confirmed, your original file is safely backed up to admin/orders.php_bos_backup before the notifiers are inserted.
  5. Enable the plugin if the Plugin Manager does not automatically enable it for you.
  6. Install any companion batch plugins (such as Batch Order Print) after installing Batch Order Select.

Features & Usage ↑ top

Once installed, navigate to Customers > Orders in your Zen Cart admin panel:

  • Leading Checkbox Column: A dedicated checkbox column appears as the very first column in the orders table, immediately before the Order ID. Each checkbox cell uses the dataTableButtonCell class so clicking a checkbox will not accidentally trigger the row click or navigate away from the listing.
  • Select All (Header Checkbox): Clicking the checkbox in the table header selects or deselects every order listed on the current page. When only some orders are selected, the header checkbox displays an indeterminate state.
  • Shift-Click Range Selection: Click any order checkbox, hold down the Shift key, and click another checkbox further up or down the table to instantly toggle every order between them.
  • Unified Action Row: A single toolbar row (.zc-bos-bar) sits neatly beneath the search filters and right above the orders table. It displays a live counter of how many orders are currently selected (e.g., "3 selected") alongside a helpful Shift-click reminder.
  • Smart Button State Management: Checkboxes only handle selection; the specific button you click determines the action performed. All batch action buttons remain disabled until at least one order is checked, preventing accidental empty submissions.

Developer Guide: Integrating Your Plugin ↑ top

Batch Order Select is designed as a foundation for other Zen Cart plugins. Rather than adding your own checkbox column to admin/orders.php or building custom JavaScript to track selected rows, your plugin simply adds its action button(s) to the shared toolbar and receives the selected Order IDs upon submission.

How Shared Checkboxes Work

When an administrator checks orders in the table and clicks any plugin's submit button inside the shared action bar, Batch Order Select intercepts the form submission in JavaScript and dynamically populates the clicked form:

  1. One Set of Checkboxes for All Plugins: Every row in the orders table renders a single checkbox (input.zc-bos-check) whose value is the order's orders_id. Checkboxes are not tied to a single wrapping <form> around the table; instead, each plugin places its own compact <form> inside the top action bar.
  2. Automatic Button Enabling/Disabling: Any button[type="submit"] or input[type="submit"] inside the .zc-bos-actions container starts with the disabled attribute. Batch Order Select automatically enables all submit buttons as soon as one or more orders are checked, and disables them again if all checkboxes are cleared.
  3. On-Submit Order ID Injection: When the admin clicks your plugin's submit button, Batch Order Select reads all currently checked boxes in table order and writes one hidden <input type="hidden"> per selected order directly into the submitted form right before it posts.
  4. Customizable Field Name: By default, the injected hidden inputs are named batch_order_ids[] (arriving in PHP as $_POST['batch_order_ids']). You can customize this input name per form using the data-zc-bos-field attribute.

How to Append Action Buttons to the Existing Row

To add your plugin's button(s) to the shared action row above the orders table, create an admin observer that listens for the NOTIFY_BATCH_ORDER_SELECT_BUTTONS event:

  • Event to Observe: NOTIFY_BATCH_ORDER_SELECT_BUTTONS (fires while the orders listing action row is being built).
  • First Parameter ($p1): An associative array containing context information: ['context' => 'orders_listing'].
  • Second Parameter (&$p2): A string passed by reference containing the accumulated HTML for the buttons inside .zc-bos-actions.
    • Append your form HTML to $p2 ($p2 .= ...).
    • Do NOT overwrite $p2, as that would erase buttons added by other plugins.
    • Do NOT wrap your output in a <div class="row">. Batch Order Select already wraps the entire toolbar in a single .row.noprint.zc-bos-bar container.
  • Form Structure Rules:
    • Give your <form> the class zc-bos-form.
    • Set data-zc-bos-field="batch_order_ids[]" (or your preferred array field name) on the <form> tag.
    • Include an empty <span class="zc-bos-ids"></span> inside the form to provide a dedicated slot where Batch Order Select will write the hidden order ID inputs on submit.
    • Render your submit button(s) with the disabled attribute initially set.

Complete Observer & Form Example

First, here is the HTML markup structure your plugin should append to $p2:

<form method="post" action="..." class="zc-bos-form" data-zc-bos-field="batch_order_ids[]">
  <span class="zc-bos-ids"></span>
  <button type="submit" name="document" value="invoice" class="btn btn-primary btn-sm" disabled>Print invoices</button>
</form>

Below is a completeZen Cart admin observer example showing how another plugin hooks into NOTIFY_BATCH_ORDER_SELECT_BUTTONS using standard Zen Cart functions:

<?php
if (!defined('IS_ADMIN_FLAG')) {
    die('Illegal Access');
}

class zcObserverMyBatchPlugin extends base
{
    public function __construct()
    {
        $this->attach($this, [
            'NOTIFY_BATCH_ORDER_SELECT_BUTTONS',
        ]);
    }

    public function notify_batch_order_select_buttons(&$class, string $eventID, $p1, &$p2): void
    {
        if (!is_string($p2)) {
            $p2 = '';
        }

        // zen_draw_form() automatically incorporates zen_href_link()
        $form = zen_draw_form(
            'my_batch_action',
            FILENAME_ORDERS,
            'action=my_batch_process',
            'post',
            'class="zc-bos-form" data-zc-bos-field="batch_order_ids[]"'
        );
        $form .= '<span class="zc-bos-ids"></span>';
        $form .= '<button type="submit" name="document" value="invoice" class="btn btn-primary btn-sm" disabled>'
            . 'Print Invoices'
            . '</button>';
        $form .= '</form>';

        // Append to $p2 — never replace $p2 or wrap in a new .row
        $p2 .= $form;
    }
}

When the admin selects orders 1001, 1004, and 1009 and clicks Print Invoices, your target controller receives:

$_POST['batch_order_ids'] = ['1001', '1004', '1009'];
$_POST['document']        = 'invoice';

Technical Details & Notifiers

Notifier / Component Purpose & Behavior
NOTIFY_ADMIN_ORDERS_LIST_LEADING_COLUMN_HEADING Fires in admin/orders.php before the Order ID column heading. Batch Order Select appends the "Select All" header checkbox cell to $leading_headings.
NOTIFY_ADMIN_ORDERS_LIST_LEADING_COLUMN_DATA Fires in admin/orders.php for each order row before the Order ID cell. Passes $orders->fields as the second parameter ($p2) so Batch Order Select reads $p2['orders_id'] directly without touching any global query result.
NOTIFY_ADMIN_ORDERS_LISTING_BUTTONS Native Zen Cart notifier (present in stock ZC 2.1.0+). Batch Order Select observes this to fire NOTIFY_BATCH_ORDER_SELECT_BUTTONS and output the unified .zc-bos-bar action row.
NOTIFY_BATCH_ORDER_SELECT_BUTTONS Fired by Batch Order Select. Third-party batch plugins observe this event and append their form.zc-bos-form markup to $p2.

Uninstallation ↑ top

  1. First, uninstall any dependent plugins that add buttons to the Batch Order Select row (such as Batch Order Print).
  2. Navigate to Modules > Plugin Manager, select Batch Order Select, and click Uninstall.
  3. No database tables or configuration rows are created by this plugin, so your database remains completely clean.
  4. Note for Zen Cart 2.1.0 – 2.2.2 users: Uninstalling the plugin does not modify or overwrite admin/orders.php. The added notifiers are harmless when no observer is attached, and the original backup made at install time remains safely stored at admin/orders.php_bos_backup.

Common Issues ↑ top

  • Install paused on Zen Cart 2.1.0 – 2.2.2: This is an intentional safety feature. The first time you click Install on a pre-2.3.0 store, the installer verifies file permissions and prompts you to confirm patching admin/orders.php. Simply click Install a second time within 15 minutes to complete the installation.
  • "admin/orders.php is not writable" error: On Zen Cart 2.2.2 and earlier, ensure that both admin/orders.php and your admin/ directory have write permissions so the installer can save admin/orders.php_bos_backup and update the file.
  • Restoring the backup manually: If you ever need to revert admin/orders.php on a pre-2.3.0 store, delete the modified admin/orders.php and rename admin/orders.php_bos_backup back to admin/orders.php.
